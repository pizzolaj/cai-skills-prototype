CAI Skills: Maze test setup

For the researcher only. Participants get the start URLs below, never this page. Each start URL opens a clean prototype with no flow bar or tips. Every screen change adds &screen=… to the URL, which is what Maze records as a step.

Set up in Maze

  1. Team settings → Connected websites: add https://pizzolaj.github.io and verify it by opening any start URL below.
  2. Add a Website test block for each task. Paste the task's start URL as the starting page.
  3. Record the expected path by clicking through it once. Add the alternates as extra success paths.
  4. Tell participants to select End task when done. Maze doesn't end website tasks on its own.

Notes

Open the prototype without a task to get the demo version with the flow bar. Chat responses are scripted, so write task prompts that steer participants to the scenario (for example, name New Brunswick and a $100 oil price). Typing unrelated requests returns a neutral “try again” message.
